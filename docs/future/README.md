self-contained brief: why the change is wanted, the design, the risks, and
a sequence to build it in.

worth keeping but the work isn't the current priority.

Each file's HTML comment header records the commit it was written against.
File paths and line numbers drift; the reasoning is the durable part, so
re-verify the specifics before acting on one.
