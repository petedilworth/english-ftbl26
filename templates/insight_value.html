Percentiles, not raw numbers: Manchester City's catchment is so large that dividing by it would leave every other club near zero. Missing data counts at the middle, which flatters clubs with little on record – the hatching shows where. Net debt is left out: only a dozen clubs file it. There are no sale prices, valuations or attendances here, so the index says which clubs have the makings of a rise, not which are good deals.
